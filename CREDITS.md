# Credits

Written and maintained by Nikita Vasilevskiy.

The protocol work behind this library is reverse engineering: BLE captures from real wheels,
firmware disassembly, and vendor application analysis. Where a decode is a hypothesis rather
than a confirmed reading, the code says so at the point where it matters.

Thanks to the riders who ran captures on wheels the maintainer does not own. A protocol is only
as good as the traffic it was checked against.

No third-party protocol source is included in this distribution. Build tooling is Kotlin
Multiplatform and Gradle.
